Ready for automations

With Mosquitto and the Home Assistant MQTT integration set up, this app creates a device with:

  • A recognition event with person, camera and score
  • A recently-seen sensor for each person
  • Counts for known people and pending groups
  • A scan button for each configured camera

Recently seen means detected in a camera image within the last two minutes. It is not whole-home presence.

Use an event trigger

In an automation, choose an entity state trigger for event.sface_recognition, then filter its event_type, person_id or camera attributes. See the app documentation for a complete example.
